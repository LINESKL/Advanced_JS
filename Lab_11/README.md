# Lab 11 — Advanced Asynchronous JavaScript

### Promises, Async/Await and Error Handling Strategies

</div>

## Описание

Глубокое изучение асинхронного программирования в JavaScript. В рамках работы реализованы сложные механизмы управления асинхронностью, включая очереди задач, стратегии повторных попыток (retries), отменяемые запросы (AbortController) и конвейеры обработки данных (Pipelines).

## Задания

### Task 1 — Advanced Async Mechanisms

Реализация инструментов для работы с асинхронностью на низком уровне: кастомный HTTP-клиент на промисах и очередь задач с ограничением конкурентности.

**Ключевые аспекты:**
- Механизм `retry` (повторные попытки при ошибках)
- Ограничение количества одновременных задач (`AsyncQueue`)
- Инкапсуляция Fetch API через классы

### Task 2 — Asynchronous Workflows & Cancellation

Создание надежных цепочек обработки данных и решение проблемы "гонки данных" (Race Conditions) с использованием отмены запросов.

**Ключевые аспекты:**
- Использование `AbortController` для отмены устаревших запросов
- Реализация `Pipeline` для пошаговой обработки данных (Transform, Filter)
- Управление сложными асинхронными состояниями UI

## Применяемые технологии

| Технология | Использование |
|-----------|----------|
| **AbortController** | Отмена HTTP-запросов |
| **Async/Await** | Чистый синтаксис асинхронности |
| **Custom Promises** | Управление очередями и задержками |
| **Fetch API** | Сетевое взаимодействие |

## Результаты работы

По завершении лабораторной работы достигнуты следующие результаты:

1. **Отказоустойчивость:**
   - Понимание паттерна `Retry` для обработки временных сетевых сбоев
   - Умение предотвращать утечки ресурсов через своевременную отмену запросов

2. **Производительность:**
   - Реализация очереди задач для оптимизации нагрузки на систему
   - Поток данных через конвейер (Pipeline) для снижения связности кода

3. **Практический опыт:**
   - Работа с современным Fetch API и AbortSignal
   - Построение сложных асинхронных архитектур без блокировки основного потока
