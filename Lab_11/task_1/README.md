# Lab 11.1: Advanced Async Mechanisms

</div>

## Обзор

В данном задании реализована инфраструктура для работы с асинхронными задачами: HTTP-клиент с обработкой ошибок и умная очередь задач.

## Файлы

- `index.html` — демо-страница для тестирования очереди и HTTP-клиента.
- `PromiseHttpClient.js` — обертка над Fetch для типизированных запросов.
- `AsyncQueue.js` — реализация очереди с ограничением на количество параллельно выполняемых задач.
- `retry.js` — утилита для автоматического перезапуска неудачных попыток.

## Ключевые механизмы

### 1. Retry Strategy
Функция для надежного выполнения задач, которые могут завершиться ошибкой (например, из-за плохого интернет-соединения). Повторяет запрос до достижения лимита попыток.

### 2. Async Queue
Ограничение количества сетевых запросов или тяжелых операций. Если в очередь добавляется 10 задач, а лимит 3 — одновременно будут выполняться только 3, остальные ждут завершения текущих.

## Примеры использования

```javascript
// HTTP-клиент с повторными попытками
const client = new PromiseHttpClient();
const data = await retry(() => client.get('/api/data'), { attempts: 3 });

// Очередь задач с лимитом
const queue = new AsyncQueue(2);
queue.run(() => doTask(1));
queue.run(() => doTask(2));
queue.run(() => doTask(3)); // эта задача будет ждать
```
