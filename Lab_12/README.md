# Lab 12 — Web Workers & Service Workers

### Background Processing & Progressive Web Apps

</div>

## Описание

Изучение многопоточности в JavaScript через Web Workers и создание Progressive Web App с использованием Service Workers. В работе реализованы механизмы фоновых вычислений, кэширования ресурсов и работы в offline-режиме.

## Задания

### Task 1 — Web Workers

Реализация фоновых вычислений с использованием Web Workers для выполнения тяжелых операций без блокировки основного потока UI.

**Ключевые аспекты:**
- Вычисление простых чисел в заданном диапазоне
- Сортировка больших массивов различными алгоритмами
- Обработка изображений с применением фильтров
- Передача данных через Transferable Objects
- Отслеживание прогресса выполнения задач

### Task 2 — Service Workers & PWA

Создание Progressive Web App с полноценной поддержкой offline-режима, кэширования и push-уведомлений.

**Ключевые аспекты:**
- Регистрация и управление Service Worker
- Стратегии кэширования (Cache First, Network First)
- Работа приложения без интернет-соединения
- Очередь offline-действий с синхронизацией
- Push-уведомления и Install Prompt
- Web App Manifest для установки на устройство

## Применяемые технологии

| Технология | Использование |
|-----------|----------|
| **Web Workers** | Многопоточные вычисления |
| **Service Workers** | Кэширование и offline-режим |
| **Cache API** | Управление кэшем ресурсов |
| **Notifications API** | Push-уведомления |
| **Transferable Objects** | Эффективная передача данных |
| **Web App Manifest** | PWA установка |

## Результаты работы

По завершении лабораторной работы достигнуты следующие результаты:

1. **Многопоточность:**
   - Понимание работы Web Workers и их жизненного цикла
   - Навык выполнения тяжелых вычислений без блокировки UI
   - Эффективная передача данных между потоками

2. **Progressive Web Apps:**
   - Реализация полноценного offline-режима
   - Управление кэшированием ресурсов
   - Создание устанавливаемого веб-приложения

3. **Производительность:**
   - Оптимизация загрузки через кэширование
   - Неблокирующая обработка данных
   - Улучшение пользовательского опыта

4. **Практический опыт:**
   - Работа с современными Web APIs
   - Построение отказоустойчивых приложений
   - Реализация фоновой синхронизации данных
