# Task 1 — Web Workers

## Описание

Демонстрация использования Web Workers для выполнения тяжелых вычислений в фоновых потоках без блокировки основного потока UI.

## Реализованные Workers

### 1. Prime Number Calculator (`primeWorker.js`)
- Поиск простых чисел в заданном диапазоне
- Отправка прогресса вычислений каждые 100 найденных чисел
- Алгоритм проверки простоты числа через перебор делителей

### 2. Array Sorter (`sortWorker.js`)
- Сортировка больших массивов различными алгоритмами
- Поддержка Quick Sort, Merge Sort, Bubble Sort
- Измерение времени выполнения каждого алгоритма

### 3. Image Processor (`imageWorker.js`)
- Применение фильтров к изображениям (Grayscale, Invert, Sepia, Blur)
- Обработка ImageData через Transferable Objects для оптимизации
- Попиксельная обработка без блокировки UI

## Ключевые особенности

- **Неблокирующий UI**: все тяжелые вычисления выполняются в отдельных потоках
- **Progress Updates**: отслеживание прогресса длительных операций
- **Transferable Objects**: эффективная передача данных между потоками
- **Worker Pool Management**: управление жизненным циклом воркеров

## Технологии

- Web Workers API
- Canvas API (для обработки изображений)
- Performance API (для измерения времени)
- ES6 Modules

## Запуск

Откройте `index.html` в браузере через локальный сервер:

```bash
# Используйте любой HTTP-сервер, например:
python3 -m http.server 8000
# или
npx serve
```

Затем откройте `http://localhost:8000`
