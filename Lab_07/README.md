# Лабораторная работа #7
## Порождающие паттерны проектирования

### Описание
Изучение и практическое применение порождающих паттернов проектирования (Creational Design Patterns) в JavaScript. Реализация паттернов Singleton и Factory для создания гибких и масштабируемых систем.

### Задачи

**Задача 1: Паттерн Singleton**
- Реализация паттерна Singleton для управления конфигурацией приложения
- Создание класса ConfigManager с гарантией единственного экземпляра
- Тестирование различных способов создания экземпляра (getInstance, new)
- Проверка согласованности данных между экземплярами

**Задача 2: Паттерн Factory**
- Реализация паттерна Factory для системы уведомлений
- Создание фабрики для генерации различных типов уведомлений (Email, SMS, Push)
- Инкапсуляция логики создания объектов
- Обработка ошибок при создании неподдерживаемых типов уведомлений

### Ключевые концепции

**Singleton Pattern:**
- Гарантирует наличие только одного экземпляра класса
- Предоставляет глобальную точку доступа к этому экземпляру
- Контролирует создание объектов через статический метод

**Factory Pattern:**
- Определяет интерфейс для создания объектов
- Делегирует решение о том, какой класс инстанцировать, подклассам
- Инкапсулирует логику создания и упрощает добавление новых типов
