# Задача 2: Паттерн Factory
## Система уведомлений

### Описание
Реализация паттерна Factory для создания системы уведомлений с поддержкой различных типов (Email, SMS, Push). Фабрика инкапсулирует логику создания объектов и обеспечивает единый интерфейс для работы с уведомлениями.

### Цели задачи
- Создать фабрику NotificationFactory для генерации уведомлений
- Реализовать различные типы уведомлений с единым интерфейсом
- Инкапсулировать логику создания объектов
- Обеспечить обработку ошибок для неподдерживаемых типов

### Реализация

**NotificationFactory.js** - фабрика уведомлений:
- Статический метод `create(type, options)` для создания уведомлений
- Switch-конструкция для выбора типа уведомления
- Метод `getSupportedTypes()` для получения списка доступных типов
- Обработка ошибок для неизвестных типов

**notifications/** - классы уведомлений:
- **EmailNotification.js** - отправка email-уведомлений
- **SMSNotification.js** - отправка SMS-сообщений
- **PushNotification.js** - отправка push-уведомлений
- Единый интерфейс `send(message)` для всех типов

**app.js** - демонстрация работы:
- Функция `sendNotification()` для отправки уведомлений
- Примеры создания и отправки разных типов уведомлений
- Обработка ошибок при неподдерживаемых типах

### Архитектура системы

| Компонент | Ответственность |
|-----------|-----------------|
| **NotificationFactory** | Создание экземпляров уведомлений, валидация типов |
| **EmailNotification** | Отправка email с темой и получателем |
| **SMSNotification** | Отправка SMS на номер телефона |
| **PushNotification** | Отправка push-уведомлений на устройство |

### Преимущества паттерна
- Инкапсуляция логики создания объектов
- Простое добавление новых типов уведомлений
- Единый интерфейс для работы с объектами
- Централизованная обработка ошибок
- Упрощение клиентского кода

### Поддерживаемые типы
```javascript
NotificationFactory.getSupportedTypes()
// ['email', 'sms', 'push']
```

### Пример использования
```javascript
// Email уведомление
sendNotification(
  "email", 
  { to: "user@example.com", subject: "Hello" }, 
  "Welcome to our service!"
);

// SMS уведомление
sendNotification(
  "sms", 
  { to: "+1234567890" }, 
  "Your verification code is 123456"
);

// Push уведомление
sendNotification(
  "push", 
  { deviceToken: "abc123_xyz", title: "New Alert" }, 
  "You have a new friend request"
);
```

### Расширяемость
Для добавления нового типа уведомлений необходимо:
1. Создать новый класс с методом `send(message)`
2. Добавить case в switch фабрики
3. Обновить метод `getSupportedTypes()`
