# Lab 13 — Advanced React Patterns

### Higher-Order Components, Custom Hooks & Context API

</div>

## Описание

Изучение продвинутых паттернов React-разработки: паттерн Higher-Order Component (HOC) для повторного использования логики, создание кастомных хуков для инкапсуляции сложных механизмов, а также работа с Context API для глобального состояния.

## Задания

### Task 1 — HOC & Context API (Themed Components)

Реализация системы темизации компонентов через React Context и Higher-Order Component. Созданы два переключаемых набора токенов (light/dark) и компоненты, автоматически получающие тему через обёртку `withTheme`.

**Ключевые аспекты:**
- Создание `ThemeProvider` с createContext
- Паттерн HOC `withTheme` через Context.Consumer
- Компоненты `ThemedButton` и `ThemedCard` с вариантами стилизации

### Task 2 — Custom Hooks Collection

Набор кастомных хуков для типичных задач frontend-разработки: API-запросы, кэширование, debounce, реактивный localStorage.

**Ключевые аспекты:**
- `useApi` — универсальный хук с abort-контролем и refetch
- `useFetch` — fetch с автоматическим кэшированием и защитой от race conditions
- `useDebounce` — задержка обновления для оптимизации частых обновлений
- `useLocalStorage` — реактивная обёртка над localStorage

## Применяемые технологии

| Технология | Использование |
|-----------|----------|
| **HOC** | Инъекция темы в компоненты |
| **Context API** | Глобальное состояние темы |
| **Custom Hooks** | Инкапсуляция логики API/Storage |
| **AbortController** | Отмена устаревших запросов |
| **TypeScript** | Типизация хуков (Task 2) |

## Результаты работы

По завершении лабораторной работы достигнуты следующие результаты:

1. **Паттерн HOC:**
   - Понимание принципов композиции и передачи пропсов
   - Навык создания переиспользуемых обёрток для компонентов

2. **Кастомные хуки:**
   - Инкапсуляция сложной асинхронной логики в простые хуки
   - Управление жизненным циклом через useEffect и useRef
   - Предотвращение утечек памяти через AbortController

3. **Архитектурное мышление:**
   - Сравнение HOC и хуков как двух подходов к повторному использованию логики
   - Умение выбирать подходящий паттерн под задачу (тема → HOC + Context, API → хуки)
