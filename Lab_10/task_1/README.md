# Lab 10.1: MVC — "Model-View-Controller"

</div>

## Обзор

Реализация классического архитектурного паттерна MVC на примере приложения Todo List. Приложение позволяет добавлять задачи, отмечать их как выполненные и удалять, полностью отделяя хранение данных от отображения.

## Файлы

- `index.html` — точка входа и декларативная разметка.
- `TodoModel.js` — хранилище данных и бизнес-логика манипуляции задачами.
- `TodoView.js` — рендеринг списка и обработка DOM-событий.
- `TodoController.js` — посредник, управляющий жизненным циклом приложения.

## Особенности реализации (MVC)

| Компонент | Роль | Ключевой функционал |
|-----------|------|--------------------|
| **Model** | Хранитель состояния | Добавление/Удаление, LocalStorage |
| **View** | Визуальное представление | Генерация HTML, Delegation |
| **Controller** | Посредник | Подписка на действия во View и обновление Model |

## Как запустить

Поскольку используются ES6 Modules, приложение должно запускаться через локальный сервер (например, VS Code Live Server или `npx serve`):

```bash
npx serve .
```
