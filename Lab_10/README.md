# Lab 10 — Architectural Patterns

### MVC and MVVM Implementation

</div>

## Описание

Изучение и практическое применение архитектурных паттернов в разработке интерфейсов. В рамках данной лабораторной работы реализованы два приложения, демонстрирующих разделение ответственности между данными, логикой отображения и пользовательским интерфейсом.

## Задания

### Task 1 — MVC Architecture (Model-View-Controller)

Реализация приложения Todo List с использованием классического паттерна MVC. Основной упор сделан на разделение бизнес-логики (Model), визуального представления (View) и связующего звена (Controller).

**Ключевые аспекты:**
- Однонаправленный поток данных
- Прямое управление View через Controller
- Реакция на события пользователя

### Task 2 — MVVM Architecture (Model-View-ViewModel)

Реализация формы редактирования профиля пользователя с использованием паттерна MVVM и механизма Two-Way Data Binding.

**Ключевые аспекты:**
- Двустороннее связывание данных (Data Binding)
- Автоматическая синхронизация View и ViewModel
- Реактивное обновление состояния

## Применяемые технологии

| Паттерн | Использование |
|-----------|----------|
| **MVC** | Управление списком задач |
| **MVVM** | Формы с валидацией и предпросмотром |
| **ES6 Modules** | Организация кода по слоям |
| **Pub/Sub / Observer** | Механизм уведомлений об изменениях |

## Результаты работы

По завершении лабораторной работы достигнуты следующие результаты:

1. **Разделение ответственности:**
   - Понимание границ ответственности между Model, View, Controller и ViewModel
   - Навык проектирования расширяемых и тестируемых систем

2. **Работа с реактивностью:**
   - Реализация собственных механизмов наблюдения за изменениями ($watch)
   - Автоматизация обновления UI при изменении данных

3. **Архитектурное мышление:**
   - Сравнение классического MVC и современного MVVM
   - Умение выбирать подходящий паттерн под конкретную задачу (простые списки vs сложные формы)
