# Lab 10.2: MVVM — "Model-View-ViewModel"

</div>

## Обзор

Реализация паттерна MVVM (Model-View-ViewModel) для управления формой профиля пользователя. В задании продемонстрировано двустороннее связывание данных (Two-way Data Binding), которое позволяет автоматически синхронизировать состояние интерфейса с бизнес-логикой.

## Файлы

- `index.html` — точка входа и стилизация формы.
- `mvvm/base/ViewModel.js` — базовый класс с реализацией механизмов реактивности (`$watch` и `defineProperty`).
- `mvvm/viewmodel/UserProfileViewModel.js` — конкретная логика формы: валидация, вычисляемые свойства (fullName, isValid).
- `mvvm/view/UserProfileForm.js` — компонент отображения, подписывающийся на изменения ViewModel.

## Механизмы MVVM

| Компонент | Роль | Реализация в проекте |
|-----------|------|----------------------|
| **View** | Структура и отображение | HTML-шаблон и делегирование событий |
| **ViewModel** | Логика отображения | Состояние формы, валидация полей |
| **Data Binding** | Связующее звено | Метод `defineProperty` и геттеры/сеттеры |

## Особенности реализации

1. **Реактивность:** Использование прокси-подобного поведения через `Object.defineProperty` для отслеживания изменений.
2. **Вычисляемые свойства:** Автоматическое обновление `fullName` и статуса `isValid` при вводе данных.
3. **Валидация на лету:** Мгновенная проверка корректности email и возраста пользователя.
4. **Сохранение фокуса:** При рендеринге View после изменений в ViewModel корректно восстанавливается позиция курсора и фокус ввода.
