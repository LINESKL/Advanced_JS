# Lab 14.2: Islands Architecture

</div>

## Обзор

Реализована архитектура Islands для e-commerce страницы: основной контент остается статическим HTML, а JavaScript подключается только к интерактивным островам (виджетам).

## Файлы

- `index.html` — страница с двумя интерактивными островами и статическими текстовыми блоками.
- `islands-engine.js` — движок обнаружения и ленивой гидрации островов.

## Ключевые механизмы

### 1. Island Registry
Объект `IslandRegistry` хранит поведение для каждого типа острова:
- `counter` — счетчик количества товара
- `color-picker` — переключение цвета предпросмотра

### 2. Discovery by Data Attributes
Движок находит все интерактивные зоны через селектор `[data-island-type]`, что упрощает масштабирование и добавление новых островов.

### 3. Lazy Hydration (IntersectionObserver)
Инициализация острова происходит только когда блок появляется в viewport. После гидрации наблюдение отключается через `unobserve`, чтобы избежать лишней работы.

### 4. Static + Interactive Split
Статический контент (описание товара, текстовые блоки) не требует JS. Интерактивность ограничена островами, что уменьшает нагрузку на клиент и ускоряет рендер.

## Пример запуска

Открыть файл `index.html` в браузере (или через локальный static server).

## Результаты

1. Понимание концепции selective/lazy hydration
2. Навык организации микрокомпонентов без SPA-фреймворка
3. Практика оптимизации клиентской инициализации через Islands-подход
