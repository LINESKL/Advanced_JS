# Задача 1: Observer & Pub/Sub
## Новостная система на основе событий

### Описание
Реализация паттернов Observer и Pub/Sub для создания новостной системы. EventBus выступает централизованной шиной событий, полностью развязывая издателей и подписчиков.

### Цели задачи
- Реализовать EventBus с методами subscribe, subscribeOnce, publish, unsubscribe
- Создать NewsPublisher для публикации статей по категориям
- Подключить различных подписчиков с разной логикой обработки
- Обеспечить безопасную отписку и обработку ошибок в колбэках

### Реализация

**pubsub/EventBus.js** - ядро системы:
- Хранение подписчиков в `Map` по имени события
- Поддержка разовых подписок через отдельный `onceEvents` Map
- Возврат функции отписки из метода `subscribe()`
- Изоляция ошибок: исключение в одном колбэке не прерывает остальных

**publisher/NewsPublisher.js** - издатель новостей:
- Публикация по конкретной категории (`news:sports`, `news:tech`)
- Параллельная публикация в канал `news:all`
- Поддержка приоритета `urgent` с отдельным событием `news:urgent`

**subscribers/** - обработчики событий:
- **EmailNotifier** — отправляет email при получении статьи
- **PushNotifier** — отправляет push-уведомление
- **DashboardWidget** — обновляет виджет на интерфейсе

### Архитектура системы

| Компонент | Роль |
|-----------|------|
| **EventBus** | Централизованная шина, хранит подписки |
| **NewsPublisher** | Публикует события в EventBus |
| **EmailNotifier** | Подписчик, реагирует на `news:all` |
| **PushNotifier** | Подписчик, реагирует на `news:urgent` |
| **DashboardWidget** | Подписчик, реагирует на категорию |

### Разница Observer vs Pub/Sub

| Observer | Pub/Sub |
|----------|---------|
| Прямая связь издатель → подписчик | Через посредника (EventBus) |
| Издатель знает о подписчиках | Издатель не знает о подписчиках |
| Синхронное уведомление | асинхронное |

### Преимущества реализации
- Полная развязка компонентов через EventBus
- Простое добавление новых подписчиков без изменения издателя
- Безопасная отписка через возвращаемую функцию
- Изоляция ошибок в колбэках
