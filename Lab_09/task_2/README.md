# Задача 2: Command & Mediator
## Система управления умным домом

### Описание
Реализация паттернов Command и Mediator для системы управления умным домом. CommandManager обеспечивает историю операций с поддержкой undo/redo, а HomeMediator координирует взаимодействие устройств.

### Цели задачи
- Реализовать паттерн Command для операций с устройствами
- Создать CommandManager с поддержкой undo/redo и историей команд
- Реализовать HomeMediator для координации устройств без прямых зависимостей
- Добавить правила автоматизации (automation rules)

### Реализация

**commands/** - система команд:
- **Command.js** — базовый интерфейс с методами `execute()` и `undo()`
- **LightCommands.js** — команды включения/выключения и изменения яркости света
- **CommandManager.js** — управляет историей команд, поддерживает undo/redo со стеком

**devices/** - устройства умного дома:
- **Device.js** — базовый класс устройства с методом `setMediator()`
- **Light.js** — лампа с управлением яркостью
- **Thermostat.js** — термостат с управлением температурой
- **SecuritySystem.js** — охранная система

**mediator/HomeMediator.js** - посредник:
- Регистрация и отмена регистрации устройств
- Метод `notify()` — получает уведомления от устройств
- Публикация изменений в EventBus (интеграция с задачей 1)
- Проверка правил автоматизации при каждом изменении

### Архитектура системы

| Компонент | Ответственность |
|-----------|-----------------|
| **CommandManager** | Выполнение команд, undo/redo, хранение истории |
| **HomeMediator** | Координация устройств, правила автоматизации |
| **LightCommands** | Инкапсуляция операций над Light |
| **Device** | Базовый класс, знает о своём медиаторе |

### Паттерн Command: принцип работы
```
CommandManager.execute(cmd) → cmd.execute() → history.push(cmd)
CommandManager.undo()       → history.pop()  → cmd.undo() → redoStack.push(cmd)
CommandManager.redo()       → redoStack.pop() → cmd.execute() → history.push(cmd)
```

### Правила автоматизации
Медиатор поддерживает декларативные правила:
```javascript
mediator.addRule({
  name: "SecurityOnAtNight",
  condition: (device, state) => device.type === "thermostat" && state.temperature < 18,
  action: (devices) => devices.get("Security").arm()
});
```

### Преимущества реализации
- Команды инкапсулируют всё необходимое для выполнения и отмены
- Медиатор устраняет прямые зависимости между устройствами
- Интеграция с EventBus обеспечивает реактивность UI
- Правила автоматизации легко добавляются без изменения устройств
