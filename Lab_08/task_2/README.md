# Lab 8.2: Event Delegation — Todo List

</div>

## Обзор

Реализация паттерна Event Delegation для эффективной обработки событий в динамическом списке задач. Вместо навешивания обработчиков на каждый элемент, используется один обработчик на контейнере.

## Файлы

- `index.html` — точка входа с UI для управления списком задач.
- `delegate/EventDelegator.js` — универсальный класс делегирования событий (click, dblclick).
- `todo/TodoList.js` — менеджер списка задач, использующий делегатор для всех взаимодействий.

## Ключевые механизмы

### 1. Event Delegation
Один обработчик событий на контейнере вместо множества обработчиков на каждом элементе:
- Обработка событий через всплытие (bubbling)
- Идентификация целевого элемента через `data-action` и `data-id` атрибуты
- Поддержка динамического добавления/удаления элементов

### 2. Data Attributes
Использование HTML5 data-атрибутов для декларативной привязки действий:
- `data-action="toggle"` — переключение статуса выполнения
- `data-action="delete"` — удаление задачи
- `data-action="priority"` — изменение приоритета
- `data-action="edit-start"` — начало редактирования (dblclick)

### 3. EventDelegator
Универсальный класс для делегирования:
- Поддержка `click` и `dblclick` событий
- Метод `delegate()` для регистрации обработчиков
- Автоматическое определение действия через data-атрибуты

## Архитектура системы

| Компонент | Роль |
|-----------|------|
| **EventDelegator** | Централизованная обработка событий контейнера |
| **TodoList** | Бизнес-логика управления задачами |
| **data-action** | Декларативная привязка действий к элементам |

## Как запустить

Откройте `index.html` в браузере (через локальный сервер или напрямую):

```bash
npx serve .
```

## Преимущества реализации

- **Производительность:** Один обработчик вместо тысяч
- **Память:** Нет утечек при удалении элементов
- **Масштабируемость:** Работает с любым количеством задач (1000+)
- **Поддержка:** Легко добавлять новые действия через data-атрибуты

## Поддерживаемые действия

| Действие | Событие | Описание |
|----------|---------|----------|
| `toggle` | click | Переключение статуса выполнения |
| `delete` | click | Удаление задачи из списка |
| `priority` | click | Изменение приоритета (High/Normal) |
| `edit-start` | dblclick | Начало редактирования текста |
