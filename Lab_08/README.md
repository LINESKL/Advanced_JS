# Lab 8 — Structural Patterns & Optimization

### Flyweight Pattern & Event Delegation

</div>

## Описание

Изучение и практическое применение паттернов оптимизации в JavaScript. В рамках лабораторной работы реализованы два подхода к улучшению производительности: структурный паттерн Flyweight для эффективного использования памяти и паттерн Event Delegation для оптимизации обработки событий.

## Задания

### Task 1 — Flyweight Pattern: Forest Rendering

Реализация паттерна Flyweight для эффективного рендеринга большого количества объектов (10,000+ деревьев) на HTML5 Canvas.

**Ключевые аспекты:**
- Разделение intrinsic state (общее состояние) и extrinsic state (уникальное состояние)
- Использование Factory для создания и кэширования flyweight-объектов
- Демонстрация экономии памяти при работе с большим количеством однотипных объектов

### Task 2 — Event Delegation: Todo List

Создание приложения Todo List с использованием паттерна Event Delegation для эффективной обработки событий в динамическом списке.

**Ключевые аспекты:**
- Делегирование событий от дочерних элементов к родителю
- Использование data-атрибутов для идентификации действий
- Поддержка динамического добавления/удаления элементов без перепривязки обработчиков

## Применяемые технологии

| Технология | Использование |
|-----------|----------|
| **Flyweight Pattern** | Оптимизация памяти при рендеринге |
| **Event Delegation** | Эффективная обработка событий |
| **HTML5 Canvas** | Отрисовка графики в Task 1 |
| **ES6 Classes** | Объектно-ориентированная структура |
| **Factory Pattern** | Создание flyweight-объектов |

## Результаты работы

По завершении лабораторной работы достигнуты следующие результаты:

1. **Оптимизация памяти:**
   - Понимание принципов разделения общего и уникального состояния
   - Реализация Factory для управления пулом flyweight-объектов
   - Демонстрация экономии ~99.97% памяти при рендеринге 10,000 объектов

2. **Оптимизация событий:**
   - Применение делегирования событий вместо множественных обработчиков
   - Работа с data-атрибутами для идентификации целевых элементов
   - Поддержка динамического DOM без утечек памяти

3. **Архитектурное мышление:**
   - Выбор паттернов для решения проблем производительности
   - Баланс между сложностью реализации и выигрышем в эффективности
   - Применение структурных паттернов на практике
