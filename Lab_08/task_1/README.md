# Lab 8.1: Flyweight Pattern — Forest Rendering

</div>

## Обзор

Реализация структурного паттерна Flyweight для эффективного рендеринга леса с 10,000+ деревьями на HTML5 Canvas. Паттерн позволяет значительно сократить потребление памяти за счет разделения общего и уникального состояния объектов.

## Файлы

- `index.html` — точка входа с UI для генерации и рендеринга леса.
- `tree/FlyweightTree.js` — flyweight-класс дерева с intrinsic state (тип, порода, цвета, размеры).
- `tree/TreeFactory.js` — фабрика для создания и кэширования общих flyweight-объектов.
- `forest/ForestRender.js` — рендерер, управляющий коллекцией деревьев и отрисовкой на Canvas.

## Ключевые механизмы

### 1. Intrinsic State (Внутреннее состояние)
Общее для всех деревьев одной породы, хранится в flyweight-объекте:
- Тип дерева (ствол, крона)
- Порода (Oak, Pine, Birch)
- Цвета (коричневый ствол, зеленая крона)
- Размеры (высота, ширина)

### 2. Extrinsic State (Внешнее состояние)
Уникальное для каждого дерева, хранится отдельно:
- Позиция (x, y)
- Масштаб (scale)
- Вращение (rotation)

### 3. TreeFactory
Кэширует flyweight-объекты по ключу (type + species + colors + dimensions):
- При создании 10,000 деревьев создается только 3 flyweight (Oak, Pine, Birch)
- Экономия памяти: ~99.97%

## Архитектура системы

| Компонент | Роль |
|-----------|------|
| **FlyweightTree** | Хранит общее состояние (порода, цвета) |
| **TreeFactory** | Создает и кэширует flyweight-объекты |
| **ForestRender** | Управляет extrinsic state и рендерингом |

## Как запустить

Откройте `index.html` в браузере (через локальный сервер или напрямую):

```bash
npx serve .
```

## Преимущества реализации

- **Экономия памяти:** 3 объекта вместо 10,000 полных копий
- **Разделение ответственности:** Factory создает, Render управляет позициями
- **Масштабируемость:** Легко добавить новые породы деревьев
