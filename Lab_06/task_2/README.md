# Lab 6.2: Pattern Selection — "The Right Tool"

</div>

## Обзор

Анализ бизнес-сценариев и выбор оптимальных паттернов проектирования с последующей реализацией на JavaScript.

## Реализованные паттерны

### 1. Observer (Сценарий 03)
Система уведомлений, обеспечивающая слабую связь между источником событий и потребителями.
*   **Файл:** `impl_scenario_03.js`
*   **Применение:** UI компоненты мониторинга.

### 2. Command (Сценарий 05)
Инкапсуляция действий в объекты для реализации механизма отмены (Undo/Redo).
*   **Файл:** `impl_scenario_05.js`
*   **Применение:** Редактор с историей действий.

## Сценарии и выбор

| № | Сценарий | Выбранный паттерн | Категория |
|---|----------|-------------------|-----------|
| 01 | Глобальный конфиг | **Singleton** | Creational |
| 03 | Уведомления | **Observer** | Behavioral |
| 04 | Стороннее API | **Adapter** | Structural |
| 05 | Undo/Redo | **Command** | Behavioral |
| 06 | Сдеривание сложности | **Facade** | Structural |

## Запуск

```bash
node impl_scenario_03.js
node impl_scenario_05.js
```
