# Lab 6.1: Pattern Classification — "The Triage"

</div>

## Обзор

Глубокий анализ 10 программных сниппетов для определения используемых в них паттернов проектирования на основе классификации GoF (Gang of Four).

## Файлы

- `classification.md` — основной отчет с детальным разбором сниппетов.
- `gof_mapping.md` — сводная таблица соответствия GoF.
- `reflection.md` — рефлексия о значении категорий паттернов.

## Категории GoF

| Категория | Цель | Примеры из задания |
|-----------|------|---------------------|
| **Creational** | Механизмы создания объектов | Singleton, Factory Method, Builder |
| **Structural** | Композиция классов и объектов | Adapter, Facade, Flyweight |
| **Behavioral** | Взаимодействие и обязанности | Observer, Command, Strategy |

## Результаты анализа

В ходе работы сниппеты были классифицированы не только по категориям, но и по уровню (Scope):
- **Class:** Фокус на отношениях между классами через наследование (напр. Factory Method).
- **Object:** Фокус на отношениях между объектами через композицию (напр. Singleton, Observer).
