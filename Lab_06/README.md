# Lab 6 — Design Pattern Categories

### GoF Classification & Pattern Selection

</div>

## Описание

Изучение классификации паттернов проектирования по версии "Банды четырех" (GoF), а также практическое применение паттернов для решения конкретных архитектурных сценариев. Работа разделена на теоретический анализ существующих решений и практическую реализацию выбранных паттернов.

## Задания

### Task 1 — Pattern Classification: "The Triage"

Классификация и анализ 10 программных сниппетов на основе трех категорий GoF: порождающие, структурные и поведенческие.

**Ключевые аспекты:**
- Определение семейства паттерна (Creational, Structural, Behavioral)
- Определение уровня паттерна (Class vs Object)
- Аргументация выбора через доказательства (evidence) в коде

**Файлы:**
- `classification.md` — подробный анализ 10 сниппетов
- `gof_mapping.md` — итоговая таблица сопоставления
- `reflection.md` — рефлексия о важности категорий паттернов

### Task 2 — Pattern Selection: "The Right Tool"

Подбор оптимальных паттернов для бизнес-сценариев и реализация выбранных решений на современном JavaScript.

**Реализованные сценарии:**
- **Scenario 03:** Система уведомлений в UI (паттерн **Observer**)
- **Scenario 05:** Система отмены действий (Undo/Redo) (паттерн **Command**)

**Файлы:**
- `selection.md` — обоснование выбора паттернов для 6 сценариев
- `decision_journal.md` — критический анализ принятых решений
- `impl_scenario_03.js` — реализация Observer
- `impl_scenario_05.js` — реализация Command

## Применяемые технологии

| Категория | Паттерны |
|-----------|----------|
| **Creational** | Singleton, Factory Method, Builder |
| **Structural** | Adapter, Facade, Flyweight |
| **Behavioral** | Observer, Command, Strategy, Iterator |
| **JS Features** | ES6 Classes, Private Fields, Arrow Functions |

## Результаты работы

По завершении лабораторной работы достигнуты следующие результаты:

1. **Систематизация знаний:**
   - Четкое понимание трех основных категорий паттернов GoF
   - Умение отличать паттерны уровня класса от уровня объекта
   - Навык выявления паттернов в существующем коде по ключевым признакам

2. **Архитектурное мышление:**
   - Способность подбирать паттерны под конкретные требования бизнеса
   - Понимание trade-offs (компромиссов) при использовании различных паттернов
   - Навык формализации процесса принятия проектных решений

3. **Практическая реализация:**
   - Опыт написания слабо связанного кода через паттерн Observer
   - Реализация инкапсулированных запросов через паттерн Command
   - Применение современных возможностей JS для реализации классических паттернов
